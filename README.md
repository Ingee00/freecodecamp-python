# FreeCodeCamp Python Projects

Collection of Python solutions while learning programming fundamentals and preparing to return to the IT field as a software developer.

## Projects

### 1. number_pattern.py
Generates a number pattern from 1 to n.
- Validates input type and value
- Handles edge cases (bool, negative numbers)
- Example: `number_pattern(4)` returns `"1 2 3 4"`

### 2. pin_extractor.py
Extracts secret codes from poems based on word length position.
- Uses nested loops and enumerate
- Demonstrates string manipulation (split, join)
- Returns PIN for each poem in the list
